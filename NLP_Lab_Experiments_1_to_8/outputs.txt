--------------------------------------------------------------------------------

[TEST CASE 1]
INPUT TWEET:

OUTPUT:
Tokens:
['learning', 'nlp', 'is', 'fun', 'and', 'exciting', '.']

========== N-GRAM MODEL ==========

Unigrams:
[('learning',), ('nlp',), ('is',), ('fun',), ('and',), ('exciting',), ('.',)]

Bigrams:
[('learning', 'nlp'), ('nlp', 'is'), ('is', 'fun'), ('fun', 'and'), ('and', 'exciting'), ('exciting', '.')]

Trigrams:
[('learning', 'nlp', 'is'), ('nlp', 'is', 'fun'), ('is', 'fun', 'and'), ('fun', 'and', 'exciting'), ('and', 'exciting', '.')]

Word Frequencies:

========== HMM MODEL ==========

HMM POS Tagging:
learning -> VBG

is -> VBZ
fun -> NN
and -> CC
exciting -> JJ
. -> .

========== COMPARISON ==========
N-Gram Model
- Learns word sequences.
- Predicts the next word based on previous words.
- Used for text generation and language modeling.

HMM Model
- Predicts Part-of-Speech (POS) tags.
- Uses transition and emission probabilities.
- Used for sequence labeling tasks.
